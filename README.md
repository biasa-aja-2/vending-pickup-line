One pickup line, 122 characters, spoken by a vending machine to a passing human. The machine has dropped snacks for strangers for years; tonight it finally speaks up, in its own world of coils, buttons and rows, and the joke turns on its one job: dropping things. The punch lands on the last two words.

> I've spent years dropping snacks for strangers, but you're the first human I'd drop everything for. Press B4 -- I'm yours.

## Run it

```sh
python3 main.py
```

The program self-checks the competition's gates (UTF-8, 1–200 characters, one line, not whitespace-only, no control characters) and refuses to write if any gate fails, then writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
